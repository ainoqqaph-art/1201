🔧 常見問題解決
================================================================================

問題: Edge WebDriver 啟動失敗
錯誤: session not created: Chrome instance exited

解決方案:
1. 檢查版本是否匹配（腳本會自動顯示）
2. 下載相符版本的 msedgedriver:
   https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
3. 替換 C:\自動化\msedgedriver.exe
4. 如仍失敗，設定 EDGE_BINARY_PATH（參考 TROUBLESHOOTING.md）

問題: 資料庫連線失敗

檢查清單:
☐ SQL Server 服務運行中？
☐ 資料庫名稱是 MicrosoftRDB？
☐ ODBC Driver 17 或 18 已安裝？
☐ Windows Authentication 有權限？

================================================================================
📊 資料庫結構
================================================================================

表 1: KeywordsMaster（關鍵字主表）
----------------------------------
KeywordID        INT              -- 唯一 ID
Keyword          NVARCHAR(200)    -- 關鍵字文字
SearchVolume     NVARCHAR(100)    -- 搜尋量（100K+, 1M+）
Region           NVARCHAR(10)     -- 地區（US, TW, JP, GB, HK, AU）
TrendRank        INT              -- 該地區排名（1-20）
CreatedAt        DATETIME         -- 建立時間

表 2: KeywordsLog（搜尋記錄表）
----------------------------------
LogID            INT              -- 唯一 ID
KeywordID        INT              -- 外鍵到 KeywordsMaster
LogDate          DATE             -- 記錄日期
CrawlTime        DATETIME         -- 爬取時間
SummaryText      NVARCHAR(MAX)    -- 搜尋結果摘要
Status           NVARCHAR(50)     -- Success / Fail
ErrorMessage     NVARCHAR(1000)   -- 錯誤訊息

💡 常用 SQL 查詢
================================================================================

# 查看今日所有關鍵字
SELECT * FROM vw_TodayKeywords ORDER BY Region, TrendRank;

# 查看今日搜尋記錄
SELECT * FROM vw_TodaySearches ORDER BY CrawlTime DESC;

# 查看特定地區 Top N
EXEC sp_GetTopKeywordsByRegion @Region = 'US', @TopN = 20;
EXEC sp_GetTopKeywordsByRegion @Region = 'TW', @TopN = 20;
EXEC sp_GetTopKeywordsByRegion @Region = 'JP', @TopN = 20;

# 查看統計
EXEC sp_GetSearchStats;

# 統計各地區關鍵字數量
SELECT 
    Region, 
    COUNT(*) AS 關鍵字數量
FROM KeywordsMaster
WHERE CAST(CreatedAt AS DATE) = CAST(GETDATE() AS DATE)
GROUP BY Region
ORDER BY 關鍵字數量 DESC;

# 查詢跨地區熱門關鍵字
SELECT 
    Keyword,
    COUNT(DISTINCT Region) AS 出現地區數,
    STRING_AGG(Region, ', ') AS 地區清單
FROM KeywordsMaster
WHERE CAST(CreatedAt AS DATE) = CAST(GETDATE() AS DATE)
GROUP BY Keyword
HAVING COUNT(DISTINCT Region) > 1
ORDER BY 出現地區數 DESC;
